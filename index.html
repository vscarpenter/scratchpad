        About Scratchpad

        Scratchpad keeps everything you write in this browser only, using IndexedDB. Nothing is uploaded, synced, or transmitted unless you deliberately create a share link—and that copy is encrypted in this browser first. There are no accounts, trackers, or analytics.

        Clearing site data (or using private browsing) will erase your notes. Back up with Export and restore with Import, both behind the backup chip at the bottom of the sidebar.

        Keep the sidebar calm as your library grows: Home shows pinned and recently edited notes, while the Folders switcher opens one folder at a time. Search opens a relevance-ranked result list across every folder in the current Notes, Archive, or Trash view. Dragging a note opens the switcher so you can drop it into its new home.

        On this device — nothing is sent

        This note is long. The email draft will be truncated; copy to clipboard to send the full note.

        Public link — uploads an encrypted copy

        A public link uploads an encrypted copy of this note’s title, text, and tags.

        • The key that decrypts it stays in the link itself and is never sent to the server, so Scratchpad can’t read a shared note.
        • Anyone with the link can read and forward it. There is no password.
        • The link stops working after the time you pick — 7 to 30 days. You can stop sharing sooner.
        • None of your other notes are uploaded, and the shared copy won’t change if you edit this note later.
